Real-Time Interview Questions and Answers
Scenario 1
Question

Production EC2 CPU utilization suddenly increases to 95%. How would you handle the situation?

Answer

Step 1:
Check CloudWatch metrics.

Step 2:
Verify whether the issue is traffic-related.

Step 3:
Review application logs.

Step 4:
Confirm Auto Scaling status.

Step 5:
Scale infrastructure if necessary.

Step 6:
Monitor recovery using CloudWatch dashboards.

Collect disk metrics.

Create CloudWatch Alarm.

Configure SNS Topic.

Subscribe email recipients.

Test alarm functionality.
