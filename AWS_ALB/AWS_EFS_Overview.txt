Key Components
EC2 Instances

Two web servers are deployed in separate Availability Zones:

ap-south-1a
ap-south-1b

This ensures high availability and fault tolerance.

Target Groups

Target Groups act as logical groups of backend servers.

Examples:

TG-80 → Web Application
TG-8080 → API Application
Health Checks

ALB continuously checks server health.

Example Configuration:

Path: /index.html
Port: 80
Interval: 10 seconds

If a server becomes unhealthy, ALB automatically removes it from traffic rotation.

Path-Based Routing

ALB routes traffic based on URL paths.

Example:

/app/* → Customer Portal
/api/* → API Servers
/admin/* → Admin Dashboard
Real-Time Organization Use Case

Consider a Banking Application:

Customer Portal
bank.com/app/*
API Services
bank.com/api/*
Admin Dashboard

A single ALB intelligently routes requests to the correct backend services, improving scalability, performance, and cost optimization.
