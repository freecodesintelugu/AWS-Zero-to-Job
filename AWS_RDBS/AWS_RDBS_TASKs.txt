Amazon RDS Hands-on Lab (Practice Tasks)
==================================================================================
Task 1: Create a VPC (Optional)

Objective: Understand the network where RDS runs.

Steps
Create a VPC (10.0.0.0/16)
Create:
2 Public Subnets
2 Private Subnets
Attach an Internet Gateway
Configure Route Tables
Create a DB Subnet Group using the two private subnets

Expected Outcome
==================================================================================

RDS can be launched inside private subnets.
Task 2: Launch an EC2 Instance

Objective: Use EC2 as the application server.

Steps
Launch an Amazon Linux 2023 instance
Install MySQL client
sudo dnf update -y
sudo dnf install mariadb105 -y

or

sudo dnf install mysql -y

Expected Outcome

EC2 is ready to connect to RDS.
